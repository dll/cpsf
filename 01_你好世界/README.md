## 🚀 快速开始

### 方式一：使用编译脚本（最简单）

进入 `src` 目录，双击 `build.bat`，即可自动编译并运行。

### 方式二：手动编译

```bash
cd src
gcc -Wall -o hello.exe hello.c
./hello.exe
```

### 方式三：使用 Make

```bash
cd src
make run
```

## 💡 学习建议

1. **不要光看不动手**：编程是练出来的，不是看出来的。哪怕只是改一个字符串，也要亲手编译运行一次。
2. **带着"进化"的眼光学习**：每学一个新东西，都问问自己——它解决了什么痛点？如果没有它会怎样？
3. **错误是最好的老师**：故意写错代码，看看编译器报什么错，试着自己修复。读错误信息是程序员的基本功。
