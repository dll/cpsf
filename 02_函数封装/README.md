# 第2阶段：函数封装 —— 给代码找个家

## 🎯 本阶段目标

从"所有代码堆在main里"进化到"用函数组织代码"，理解函数封装的核心思想。

## 📁 目录结构

```
02_函数封装/
├── src/
│   ├── atm_bad.c      # 进化前：屎山main（反面教材）
│   ├── atm_good.c     # 进化后：函数封装（正面教材）
│   └── build.bat      # 编译脚本
├── docs/
│   ├── 课件.md        # Markdown课件
│   └── 课件.pptx      # PPT课件
├── video/
│   └── 讲解.mp4       # 讲解视频
├── 思考题.md          # 思辨测试题
└── README.md          # 本文件
```

## 🚀 快速开始

### 1. 编译

双击 `src/build.bat`，或者在命令行执行：

```bash
cd src
gcc atm_bad.c -o atm_bad.exe
gcc atm_good.c -o atm_good.exe
```

### 2. 运行

```bash
# 先看看"屎山"版本
atm_bad.exe

# 再看看封装版本
atm_good.exe
```

### 3. 对比思考

- 两个版本功能完全一样吗？
- 哪个版本的代码更容易读懂？
- 如果要加一个"转账"功能，哪个版本更好加？
- 如果登录逻辑出了bug，哪个版本更容易排查？

## 💡 本阶段重点

1. **为什么需要函数？** —— 代码复用、逻辑清晰、便于维护
2. **函数的组成** —— 返回值、函数名、参数、函数体
3. **声明 vs 定义** —— 接口（.h）和实现（.c）的雏形
4. **封装思想** —— 把复杂的东西包起来，对外只露接口

## 🔗 前后关系

- **上一阶段**：表达式——最基础的代码单元
- **本阶段**：函数封装——把表达式组织成有名字的代码块
- **下一阶段**：模块化编程——把函数拆到不同的文件里

---

> 🎮 编程就像搭积木：表达式是最小的积木块，函数是用积木拼好的小组件，模块是更大的组件，框架就是一整套乐高城市！
