## 🎯 本讲目标

- 理解三种基本控制结构：顺序、分支、循环
- 掌握 if-else 和 switch 两种分支语句
- 掌握 while 和 for 两种循环语句
- 通过 ATM 菜单案例，理解控制结构如何构建交互程序
