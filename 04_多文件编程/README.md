## 🎯 本讲目标

- 理解为什么需要多文件：单文件的痛点 → 多文件的优势
- 掌握头文件(.h)与源文件(.c)的关系与分工
- 理解头文件保护（#ifndef / #define / #endif）的作用与原理
- 掌握 static 关键字的两种用法（函数级 vs 文件级）

