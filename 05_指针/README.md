## 🎯 本讲目标

- 理解指针的本质：指针就是地址，地址就是内存中的"门牌号"
- 掌握取地址（&）和解引用（*）两个核心操作
- 学会用指针作为函数参数，解决值传递的局限
- 理解指针与数组的密切关系
