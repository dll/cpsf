## 🎯 本讲目标

- 理解为什么需要数组：从"单变量"到"批量管理"
- 掌握一维数组的定义、初始化、遍历
- 理解字符数组与字符串的关系（C语言没有 string 类型）
- 掌握数组作为函数参数时"退化为指针"的本质
