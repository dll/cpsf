## 🎯 本讲目标

- 理解为什么需要链表：从"固定数组"到"动态链表"
- 掌握单链表的结构（数据域 + 指针域，火车车厢比喻）
- 掌握链表创建与销毁（malloc/free，内存泄漏问题）
- 掌握增：头部插入 / 尾部插入
