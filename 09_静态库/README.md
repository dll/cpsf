## 🎯 本讲目标

- 理解静态库的概念：把多个目标文件打包成一个归档文件
- 掌握 ar 工具的使用：ar rcs libaccount.a account.o transaction.o
- 理解静态链接原理：链接器从库中"复制"代码到可执行文件
- 了解静态库的优缺点：执行快但体积大、更新需重新链接
