## 🎯 本讲目标

- 理解静态库的三个痛点：体积大、内存浪费、更新麻烦
- 理解动态库的概念：.so / .dll、导入库、导出符号
- 掌握编译动态库：Linux 用 -fPIC -shared，Windows 用 -shared
- 理解"加载时链接"原理：exe 里只有导入表 IAT，OS 启动时把库映射进进程
