## 🎯 本讲目标

- 理解第10讲"加载时链接"的死依赖：程序一启动就必须有库，缺库直接起不来
- 理解运行时加载：加载时机、加载对象由**程序自己**在运行中决定
- 掌握两套平台 API 的对照：dlopen/dlsym/dlclose ↔ LoadLibrary/GetProcAddress/FreeLibrary
- 掌握跨平台封装：用 #ifdef _WIN32 把平台差异关进 dynlib.h
