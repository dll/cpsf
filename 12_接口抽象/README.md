## 🎯 本讲目标

- 理解从运行时加载到接口抽象的进化：光能加载还不够，需要统一调用方式
- 回顾函数指针（第5讲已介绍）：指向函数的指针
- 掌握结构体接口：把多个函数指针打包成接口，类似面向对象的接口
- 掌握插件注册机制：插件加载后注册到链表（衔接第8讲链表）
