## 🎯 本讲目标

- 理解插件的**完整生命周期**：init → start → execute → stop → cleanup 五阶段
- 掌握**状态机**：UNLOADED → LOADED → INITIALIZED → STARTED → STOPPED → CLEANED
- 实现**插件管理器**：用链表统一管理所有插件的加载/启动/停止/清理
- 理解**扩展点设计**：插件能挂到哪些"插槽"（菜单项、命令、事件）
