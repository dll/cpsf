==============================================
            第13讲 核心收获
==============================================
  1. 生命周期：UNLOADED -> LOADED -> INITIALIZED
               -> STARTED -> STOPPED -> CLEANED -> UNLOADED
  2. 插件管理器：链表 + 批量 init/start/stop/cleanup
  3. 扩展点：菜单项 / 命令 / 事件，都由插件动态挂载
  4. 配置化菜单：菜单项 = 链表节点（第8讲链表的实战）
  5. 开闭原则：新增插件零改动主程序
  6. 框架 vs 库：库是你调用它，框架是它调用你（IoC）
