# CPSF：从程序员到架构师

> **C**语言 **P**lugin **S**oftware **F**ramework —— C语言插件框架演进教程

---

## 🎯 这是什么？

这是一套**从0到1的软件架构演进教学系列**。

我们从最简单的一行C代码 `printf("Hello World")` 出发，经历 **10次进化**，最终抵达一个完整的**插件框架**。每一步都只引入一个新概念，每一步都解决前一阶段的真实痛点。

```
一行代码 → 函数 → 模块 → 静态库 → 动态库 → 运行时加载
         → 接口抽象 → 插件发现 → 插件框架 → 实战应用
```

---

## 🚀 为什么做这个？

大三学生学了C语言、面向对象、数据结构，但常常有一个困惑：

> "我会写代码，但我不知道软件是怎么从一行行代码变成一个庞大的系统的？"

这套教程就是来回答这个问题的——**让你亲眼看到软件架构的演进过程**。
